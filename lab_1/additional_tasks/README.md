# Дополнительное задание к лабораторной работе № 1

**Задание.** Синтезировать и воспроизвести мелодию из фильма «Пираты Карибского моря». Для каждой ноты задать частоту и длительность, сформировать синусоидальные отсчёты и объединить их в звуковой сигнал.

| Файл | Реализация |
| --- | --- |
| [`additional_task.py`](additional_task.py) | Вычисляет частоты по названиям нот, строит график сигнала и воспроизводит мелодию. |
| [`additional_task.m`](additional_task.m) | Синтезирует мелодию по заданным частотам, сохраняет непрерывность фазы между нотами и воспроизводит сигнал. |

Для запуска Python из корня репозитория:

```bash
python -m pip install numpy matplotlib sounddevice
python lab_1/additional_tasks/additional_task.py
```

Для запуска в MATLAB открой `additional_task.m` и нажми **Run**.
