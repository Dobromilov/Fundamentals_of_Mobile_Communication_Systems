# Основы систем мобильной связи

Лабораторные работы по дисциплине «Основы систем мобильной связи». Выполнил Добромилов Артём, группа ИКС-433.

## Лабораторная работа №1. Дискретизация и преобразование Фурье

Для варианта 9 исследовали сумму косинусов на частотах 8 и 32 Гц. Сравнили дискретизацию с частотами 64 и 256 Гц, построили односторонние амплитудные спектры и восстановили отсчёты обратным ДПФ. В MATLAB сравнили исходную и прореженную записи голоса и рассчитали среднюю ошибку квантования для разрядности от 3 до 6 бит.

Применили теорему Котельникова для выбора частоты дискретизации, прямое и обратное дискретное преобразование Фурье для перехода между временным и частотным представлениями и равномерное квантование с `2^n` уровнями для `n` бит.

Код находится в [`lab_1`](lab_1). Основной расчёт сигнала — [`main.py`](lab_1/main.py), обработка записи — [`lab_1.m`](lab_1/lab_1.m).

[Дополнительное задание: мелодия из фильма «Пираты Карибского моря»](lab_1/additional_tasks).

## Лабораторная работа №2. Проектирование радиопокрытия

Рассчитали бюджеты восходящего (UL) и нисходящего (DL) каналов и максимально допустимые потери (MAPL). Сравнили модели UMiNLOS, COST 231 Hata и Walfish–Ikegami (NLOS). Для макросот использовали COST 231 Hata, для микросот — UMiNLOS. По меньшему из радиусов UL и DL рассчитали площадь покрытия одной БС и оценили число БС для заданной территории.

В бюджете канала учли мощности передатчиков, усиления, потери, запасы и чувствительность приёмника. Радиус нашли по условию `PL(R) = MAPL`.

Основной расчёт — [`lab_2/main.py`](lab_2/main.py).

[Дополнительное задание: 3D-графики чувствительности приёмников](lab_2/additional_tasks).
